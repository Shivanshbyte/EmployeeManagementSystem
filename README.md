# EMS Employee Management System with React JS and Spring Boot👨‍💻

## Tech Stack
- React.js
- Spring Boot
- PostgreSQL
- JPA/Hibernate
- Bootstrap

## Features
- CRUD Operations
- Search Employees
- Server-side Pagination
- Form Validation

## Run Frontend
cd ems-fullstack
npm install
npm run dev

## Run Backend
cd ems-backend
mvn spring-boot:run
